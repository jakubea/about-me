# About Me

Personal portfolio site built with Elm and Vite.

## Stack

- Elm 0.19.1
- Vite 5
- elm-css
- pnpm

## Development

```bash
pnpm install
pnpm dev
```

The dev server runs on `http://localhost:3001`.

## Main Scripts

```bash
pnpm dev
pnpm build
pnpm preview
pnpm test
pnpm review
pnpm format
pnpm precommit
```

## Project Notes

- production output is written to `build/`
- localization work is in progress and currently hidden in the UI
